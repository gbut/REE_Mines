# Burma Rare Earth Mines Dashboard: notes for Claude

This repository holds a single-page satellite-map dashboard of in-situ leach rare earth mines in Kachin and Shan states, Burma (Myanmar).

- **Live site:** https://gbut.github.io/REE_Mines/ (GitHub Pages, served from `main` at `/`). Every push to `main` redeploys it within about a minute.
- **Owner:** gbut. The owner prefers "Burma" in prose, though data sources say "Myanmar".

## Layout

| Path | Role |
|---|---|
| `index.html` | **Built file. Do not hand-edit.** Generated by `build.py`. |
| `src/template.html` | The page's markup, styles and script. Make page changes here. |
| `src/data/sites_snapshot.json` | Saved copy of the Stimson and Myanmar Witness sites, plus the Myanmar outline (compact coded format; see below). |
| `src/data/archive_snapshot.json` | Saved copy of the BVC Archive "Articles and Reports" rows: `[date, title, source, author, notes, link]`. |
| `src/data/admin1.json` | Kachin and Shan states, plus the bordering Chinese provinces Yunnan and Tibet/Xizang (Natural Earth 10m admin-1, rounded to 3 dp). |
| `src/data/snapshot.json` | The date the saved copies were taken. Shown on the page. |
| `reports.json` | The Reports tab. The page fetches it live; a copy is also embedded at build time. |
| `build.py` | Builds `index.html`. Run `python3 build.py --check` to confirm the built file is current. |

## Workflow for any change

1. Edit `src/template.html`, files in `src/data/`, or `reports.json`.
2. Run `python3 build.py`, then `python3 build.py --check`.
3. Test locally if the change touches the script. Chrome is at `/usr/bin/google-chrome`; use playwright-core with `--allow-file-access-from-files`. Load the page and check for page errors and the counts in the header. The sandbox can't reach Google or ArcGIS, so the page falls back to the saved copies. To test the live code paths, intercept the requests with `page.route` and return mock CSV/JSON.
4. Commit and push to `main`. After about a minute, open the live site and confirm the header status reads "live" for each source.

The page loads each source live on every visit, and falls back to its embedded copy if the request fails.

| Reports | `reports.json` in this repository | Claude's own finds. Must not repeat anything in the BVC Archive (either section), including reposts of the same story. |

Calculated in the browser: the "near China border" flag and the nearest site in the other dataset.
- **Border flag:** the distance in km beyond the Natural Earth 1:10m Myanmar outline. Points are kept and flagged, not dropped, because every source records them in Kachin.
- **Overlap:** 228 of the 237 Myanmar Witness sites lie within 300 m of a Stimson point.

### `reports.json` schema

```json
{"type": "News|Report|Analysis|Data", "org": "Publisher (\"X via Y\" for reposts)", "date": "YYYY-MM-DD | YYYY-MM | YYYY | \"\"",
 "title": "Actual headline", "url": "https://…", "note": "One sentence in Claude's own words", "added": "YYYY-MM-DD"}
```

Items added in the last 30 days show a "New" tag. Keep 1-space indentation.

### `sites_snapshot.json` format

The file is an object with these keys:

| Key | Contents |
|---|---|
| `P` | States |
| `F` | Basins |
| `B` | Sub-basins |
| `S` | Credited-source strings; index 4 = "(not given)" |
| `T` | `[township, state]` pairs |
| `mm` | Myanmar outline geometry |
| `s` | Stimson rows: `[id, year\|null, P-index, F-index, B-index, lat, lon, S-index, km_outside_border, nearest_MW_id, nearest_MW_m]` |
| `m` | Myanmar Witness rows: `[id, lat, lon, year, pits, T-index, image_item_id, km_outside_border, nearest_S_id, nearest_S_m]` |

## Refreshing the saved copies

This is optional: the live site doesn't depend on the saved copies.
- The cloud sandbox's shell can't reach docs.google.com or arcgis.com.
- Fetch the data with the desktop app's built-in browser, if available. `javascript_tool` on any https page can `fetch()` the URLs above.
- Rebuild the files in the formats above, update `src/data/snapshot.json`, run `build.py`, and verify row counts against the live source before committing.
